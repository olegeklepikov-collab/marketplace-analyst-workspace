Внутренние средства ИИ-агента

Этот справочник обращён к исполняющему ИИ-агенту. Руководитель задаёт работу естественным языком; перечисленные операции агент выполняет сам и не возвращает их человеку как обязательные действия. Для чтения используйте HTML. Программа помогает при приёме, поиске и подготовке рабочих файлов. Запуск из корня папки:

python3 00_Сервис/analyst_folder.py

В меню: 1 — подготовить поступление, 2 — включить, 3 — создать задание, 4 — обновить представления, 5 — проверить базу, 6 — проверить учёт и обновить HTML работы, 0 — выйти.

КомандаНазначение

check-work путьПроверить учёт материалов и выбранных направлений
render-work путьСоздать/обновить HTML основного Разбор.md со служебным договором, созданным work
check-edit До.md После.mdСопоставить защищённый текст, адреса и ID
refreshПересобрать каталоги и автоматически создаваемые представления
checkПроверить сохранность, структуру и локальные переходы

Глобальный --root ставится перед командой. По умолчанию программа из 00_Сервис использует родительскую папку. Стандартного Python 3.9+ достаточно; дополнительных пакетов и сервера нет.

Основной пользовательский текст — Markdown. Не редактируйте машинные указатели и автоматически создаваемые HTML: программа сохраняет ручное изменение и сообщает о конфликте. Для изменения заключения редактируется Разбор.md, затем используется render-work.

Отдельные V0/V1, задание или проект без служебного договора не преобразуются командой render-work. Сохраните их в Markdown и включите нужные разделы в основной Разбор.md: весь результат будет доступен в его HTML. Учёт и договор не следует копировать в дополнительные документы ради преобразования.

Примеры входных JSON лежат в Примеры ввода. Они учебные: перед реальным применением замените постановку и сведения. В Сравнение.json первичный вопрос об оплатах намеренно недоступен и отделён от описания заказанных штук.

Программа не проводит экспертный анализ и не размещает карточки на площадках. Полный рабочий порядок изложен в обучении.
